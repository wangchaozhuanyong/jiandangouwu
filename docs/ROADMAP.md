- [x] Hero 三 placement、移动图片、目标与次按钮字段，以及三个广告开关的契约、D1 和 API 基础。

阶段二当前只授权不同商品的人工订单基础，不包含数量、持久化或跨设备购物车、支付、会员或自动发货。阶段一 DEMO 页面仍不是正式能力证据，正式页面接入和部署尚未完成。

## 暂缓

- 线上支付闭环与资金对账闭环：本期不接入，冻结状态明确，直到所有者再次确认开启支付系统对接为止。
- 在线支付、Webhook、自动退款、结算和外部对账。
- 数量选择器、持久化或跨设备购物车。
- 客户登录、会员、积分和优惠券。
- 自动发货、自动履约、自动订阅开通和自动续费。
- 联系方式订单查询仍暂缓；联系方式不得直接枚举订单，必须先有独立所有权验证。随机 Token 方案本期不做。
- 自有域名。
- D1 无人确认自动切换与自动回滚。
- 邮件邀请投递和跨账号会话；当前邮箱预授权不会发送邮件，也不建立跨账号会话。
- 自动删除生产数据；从预览改为执行需要再次明确确认。

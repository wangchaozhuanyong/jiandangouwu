# 测试、证据与发布

## 必过门禁

```bash
npm ci
npm run check
npm run build:sites
```

核心覆盖包括：

- Telegram 幂等、联系方式密文静态保护与发送时解密、中文状态、429/5xx、超时、六档重试和最终失败。
- 系统告警高优先级筛选、备份失败/卡住去重、脱敏消息、真实 Telegram 回执、六档重试、最终失败和有原因的人工重试。
- ECB 交叉换算、Coinbase USDT、并发同步、手动模式、异常与陈旧数据。
- 隐私请求、匿名化、旧/新密钥读取、轮换中断和备份恢复。
- 客户站、后台桌面、390px 与 320px 布局。

## 发布证据

1. 工作树干净，完整检查通过。
2. 推送的提交与打包源码完全一致。
3. 保存 Sites 版本，再部署该版本。
4. 核验部署状态为成功。
5. 匿名访客可浏览；后台仍要求 ChatGPT 身份。
6. 客服和接单仍关闭。
7. Telegram 只有真实群消息回执才标记连接；汇率只有 D1 来源时间与同步记录才标记成功。

本地退出码、保存按钮或模拟消息不构成上线证据。

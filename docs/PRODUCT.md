# CloudBridge 产品范围

CloudBridge 是中英文 AI 工具服务展示与人工联系下单平台。客户无需账号，不提供购物车或数量选择器；管理后台由 ChatGPT 身份保护。

## 已实现

- Sites Worker、D1、R2 和 ChatGPT 管理员身份。
- 公开商品、分类、轮播、政策、币种、搜索和人工订单。
- 后台商品、内容、联系方式、客服、接单门禁、订单和审计。
- Telegram 真实通知队列：脱敏白名单、幂等、六档重试、真实回执和人工重试。
- ECB 法币与 Coinbase USDT/MYR 自动汇率；逐币种 AUTO/MANUAL、异常波动拒绝和陈旧失败关闭。
- D1 备份、隔离恢复演练与人工批准恢复。
- 保留策略草案、清理预览、隐私请求、HMAC 查询哈希、版本化密文和双密钥轮换。

## 当前生产门禁

公开浏览允许。真实联系方式未配置前，客服和接单保持关闭。启用顺序固定为：

1. 后台填写并启用至少一个真实联系方式。
2. 开启客服。
3. 开启接单。

自动清理保持关闭；密钥轮换只有在 `CLOUDBRIDGE_DATA_KEY_NEXT` 已配置时可执行。

## 暂缓

- 在线支付、Webhook、自动退款和外部对账。
- 自有域名。
- 无人确认的 D1 自动切换或自动回滚。
- 管理员邀请和跨账号会话管理。

页面可点击、模拟预览、本地测试和构建都不能替代真实外部回执或生产部署证据。
